🔧 BUGS WE FOUND & HONESTLY FIXED Adversarial Self-Audit · 6 Critical Fixes
Round 3
Model Collapse
LSTM giving 100% false-positives on all benign traffic
Discovered during internal red-team testing — the LSTM classified ALL traffic as malicious, including normal GET /products requests. System was essentially unusable.
✅ Root cause: Unclipped gradients in custom backprop causing weight explosion. Fixed via PyTorch migration with gradient clipping (clip_grad_norm=1.0) + regularisation. Detection recovered to 99.7%.
Round 5
Bypass Found
SQLi bypass via MySQL comment injection (/*!50000*/)
Red-team found that MySQL version-conditional comment payloads completely bypassed all regex rules — a real-world evasion technique used in live attacks.
✅ Fixed: SQL AST tokenizer strips comments pre-parse. Detects injection regardless of encoding or comment injection. Verified against 70+ bypass variants.
Round 6
Data Integrity
Dashboard SHAP values were fabricated (hardcoded fake numbers)
Early dashboard displayed hardcoded SHAP feature values that were not actually computed by the model. Looked realistic but were completely static demo placeholders.
✅ Removed all fabricated attribution. Now uses actual GradientExplainer output from PyTorch model. All displayed values are real computed outputs.
Round 7
Counter Bug
Attacks Blocked counter permanently stuck at 0
Frontend "Attacks Blocked" KPI always showed 0 despite real blocks occurring. Backend returned stats.danger but frontend looked for s.blocked (undefined field mismatch).
✅ Fixed: proxy.js now returns both blocked and danger fields. Frontend uses persistent client-side counter with real-time WAF sync + CSS pulse on increment.
Round 4
Layout Break
Dashboard boxes stretching to full viewport height
CSS align-items:stretch on flex containers caused log feed, timeline, and benchmark containers to expand to the tallest sibling's height — visually broken on all screens.
✅ Fixed: Reverted to align-items:start with explicit fixed heights. Tested across 1080p, 1440p, and 13-inch screens.
Round 1
Proto Pollution
Prototype pollution attack bypassing detection entirely
Early versions missed __proto__ pollution payloads in JSON bodies — they passed clean and could silently modify Object.prototype on the target server.
✅ Fixed: Engine now deep-scans JSON body for prototype-pollution patterns. Added verify-ldap-proto-learning.js test suite to catch future regressions.
