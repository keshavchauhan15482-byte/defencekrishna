Round 3 · Model Collapse
LSTM giving 100% false-positives on ALL benign traffic
Discovered during internal red-team testing — the LSTM classified ALL traffic as malicious, including normal GET /products. System was unusable in this state.
✅ Fixed: Unclipped gradients in custom backprop causing weight explosion. PyTorch migration with gradient clipping (clip_grad_norm=1.0) + regularisation. Detection recovered to 99.7%.
Round 5 · Evasion Bypass
SQLi bypass via MySQL comment injection (/*!50000*/)
Red-team found that MySQL version-conditional comment payloads completely bypassed all regex rules — a real-world evasion technique used in live attacks.
✅ Fixed: SQL AST tokenizer strips comments pre-parse. Detects injection regardless of encoding. Verified against 70+ bypass variants.
Round 6 · Data Integrity
Dashboard SHAP values were fabricated (hardcoded fake numbers)
Early dashboard displayed hardcoded SHAP feature values not actually computed by the model — completely static demo placeholders that looked realistic.
✅ Fixed: All fabricated attribution removed. Now uses actual GradientExplainer output from PyTorch model. All values are real computed outputs.
Round 7 · Counter Bug
Attacks Blocked counter permanently stuck at 0
Frontend "Attacks Blocked" KPI always showed 0 despite real blocks occurring. Backend returned stats.danger but frontend looked for s.blocked (undefined field mismatch).
✅ Fixed: proxy.js now returns both blocked and danger fields. Frontend uses persistent client-side counter with real-time WAF sync + CSS pulse animation on increment.
Round 4 · Layout
Dashboard boxes stretching to full viewport height
CSS align-items:stretch caused log feed, timeline, and benchmark containers to expand to the tallest sibling's height — visually broken on all screen sizes.
✅ Fixed: Reverted to align-items:start with explicit fixed heights on all variable-height containers. Tested across 1080p, 1440p, 13-inch displays.
Round 1 · Zero-Day Miss
Prototype pollution attack bypassing detection entirely
Early versions missed __proto__ pollution payloads in JSON bodies — they passed clean and could silently modify Object.prototype on the target server.
✅ Fixed: Engine now deep-scans JSON body for prototype-pollution patterns. Added verify-ldap-proto-learning.js regression test suite.
