GARUDA TECHNOLOGY

A graph world model with a temporal forecasting core.

The active inference path validates contiguous observed graph history, encodes network relationships, rolls the model forward across future horizons, calibrates the risk output, and returns provenance plus explanation metadata to the UI.

01

Graph representation

The runtime supports protocol / service graphs and host graphs. Features and adjacency are masked to active nodes, and inference rejects malformed graph dimensions or non-finite values.

02

Temporal model

The production demo checkpoint is exposed as a directed graph encoder with an LSTM temporal forecaster. The homepage loads the exact active architecture and horizon from runtime metadata after authentication.

03

Support gating

If observed traffic falls outside the checkpoint's configured training support, the service withholds the prediction. Out-of-support traffic is not silently relabelled benign.

04

Calibrated risk

The model returns a forward sequence of malicious-flow scores and an alert threshold. The dashboard visualizes the score as risk while keeping the distinction from verified compromise probability explicit.

Checkpoint integrity

The inference service verifies the active model file hash against stored metrics metadata before using it.

Stage handling

Supervised tactic outputs are shown only when the checkpoint carries supported stage metadata. Otherwise the UI keeps the stage unresolved or clearly marks heuristic hints.

Uncertainty

The forecast response can include state intervals. The runtime describes them as model uncertainty estimates rather than guarantees.
