# Locked UI direction

The approved visual direction is the second generated Garuda AI concept shown in the design review: a dark indigo / black premium cybersecurity product experience with electric blue and violet gradients, a large Garuda/eagle hero visual, a circular live risk meter, compact KPI cards, luminous line charts, a dense but clean dashboard grid, and a three-module Arjuna / Krishna / Sudarshana section.

Implementation rules:
- Preserve the purple/blue premium visual language across every public page.
- Keep the homepage composition closest to the concept: product hero + large circular risk gauge + Garuda visual + KPI strip + forecast/network panels + three defence modules.
- Runtime values must come from existing APIs or current forecast responses. Do not insert decorative accuracy, endpoint, traffic-volume, or threat-count claims.
- Recorded replay, uploaded capture, review/enforcement state, and evidence boundaries stay visible.
- Additional pages use the same navigation, typography, glass panels, gradients, spacing, and Garuda visual language.
