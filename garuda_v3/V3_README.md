# Krishna Defence / Garuda AI V3

Offline-first cyber-defence research prototype for SIH26153.

Architecture: PCAP/CSV/Flow → Feature + Graph Builder → Observed State Sequence → Garuda LSTM + Graph Dynamics → K-step future forecast → Risk/Transition evidence → Defence Router → Arjuna/Krishna/Sudarshana.

Garuda AI is an autoregressive network-state world-model approximation built around temporal and graph learning. Arjuna handles reviewed known-threat detection/blocking. Krishna handles novel/unsupported investigation, evidence retention and learning. Sudarshana provides scoped, operator-approved lockdown controls with expiry and auditability.

This repository contains historical experiments and later hardening/evaluation tracks. Release claims must be taken from the latest evidence files and must not overstate verified compromise lead time, supervised MITRE progression, real-world zero-day prevention, or autonomous enterprise containment.
