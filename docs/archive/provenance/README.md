# Archived provenance snapshot

`MANIFEST_SHA256.pre-cleanup.json` is the repository-wide SHA-256 path manifest from the pre-cleanup layout.

It is preserved as historical audit evidence only. Its paths and the hash of `README.md` correspond to the repository layout before the release-surface cleanup, so it must not be interpreted as a manifest of the current tree.

Current V48 and V52 evidence carry their own frozen configuration/source hashes and provenance records. A new repository-wide manifest should only be generated from the exact final release tree, never by reusing this historical snapshot.
