# Free cloud Garuda inference
The existing free Render web service can load the pinned packet-trained host
risk checkpoint and run on-demand inference on a private authenticated export
of closed, recent packet-feature graphs. The service does not capture the
Vercel network. No new paid resource, public inference route, raw packet upload,
or synthetic observation is introduced. Existing support gate remains mandatory;
the legacy checkpoint has no fitted support gate, so prediction is withheld.
Private status is readiness, not a live forecast. No cloud inference results
are promoted to the public feed until source continuity is independently verified.
The Render free service can sleep; 24/7 operation is not guaranteed.
