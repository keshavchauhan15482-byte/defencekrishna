# Judge demonstration and packet release boundary

The live hosted HTTP forecast predicts recorded page counts with an experimental
conditional risk trajectory. Its index is not an attack probability. The
hosted dummy route verifies real HTTP 403 decisions and the receipt feed reports
the responsible guard. Individual prediction correlation and pre-compromise
lead time are unavailable. Do not describe a dummy denial as a live compromise.

The original packet GNN+LSTM is loaded on Render, but the external authenticated
packet sensor is stale, and the legacy model lacks a fitted support gate.
The existing legacy development-held-out risk policy reported 100% false
positives. The separate V116 development state-forecast candidate reports raw
reconstructed MSE 0.017789 vs persistence 0.020818 on validation and 0.029665 vs
0.031056 on Phase 2; this is state reconstruction evidence, not attack prediction.
It is not a deployment validation or independent new holdout.

The candidate audit fits support only on training/validation histories, checks
the frozen risk policy against stored test labels and hashed predictions, and
reports coverage, accepted-negative FPR and all-positive recall. A second
isolated candidate is trained with a fixed seed and the existing development
split, not tuned to the holdout. Neither is promoted automatically. A successful
workflow means the audit ran; it does not imply the model passed the gates.
Independent packet data and a new external campaign validation are required
before release. No Vercel/Render design, API, model, or settings change.
