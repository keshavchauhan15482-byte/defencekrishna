# Compact hosted console and forecast validity

Hosted-only compact layout retains defence counters, the threat-trajectory chart,
cloud traffic counts, the authorized attack walkthrough and fixed dummy HTTP
checks, and a short system description. The private research UI and stored
evidence are not removed. A block counter counts confirmed fixture denials only,
in the current browser tab, and never credits an unattributed edge response.

The graph uses a server clock and the actual cutoff plus model horizons, not
relay receipt time. A fresh continuous supported forecast and healthy sensor
are required for an active advisory score. Expired, unsupported, offline or
gapped forecasts show no live score; historical model points remain visibly
archived and never count as a current alert. The live status updates even if
the browser has not received a new event. No model output is synthesized.

The Render relay receives completed packet-model outputs. It does not capture
traffic at the Vercel ingress, and the first-party page counts cannot replace
packet-model features. A genuine authorized, supported, fresh packet source at
the protected ingress is still needed for continuous cloud forecasting. This
change does not fabricate forecasts, activate automatic blocking or certify
pre-compromise prediction. No new cloud service or billing changes are made.
